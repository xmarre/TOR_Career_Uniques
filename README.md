# TOR Career Uniques

TOR Career Uniques adds 22 persistent career-themed encounters, five-piece unique sets, discovery and mastery progression, recruitment/succession, escalation, tavern rumours, and MCM administration for **Bannerlord 1.3.15** with **The Old Realms WiTM 1.16**.

## Repository layout

- `src/` — authoritative source for all five runtime assemblies
- `Modules/TORCareerUniques/SubModule.xml` — Bannerlord module manifest
- `docs/` — maintained encounter, item, set, and enchantment references
- `scripts/` — deterministic source verification, build, and release packaging
- `.github/workflows/` — pull-request validation and tagged release publication

Release binaries are produced by the repository workflow and published as clean and full-source archives. See [BUILD.md](BUILD.md) for the local build process and [CHANGELOG.md](CHANGELOG.md) for version history.
