# Career Set Catalogue

Each supported career has a five-piece set: its career relic plus four lore-specific armour pieces. Every armour piece keeps its first/signature intrinsic property and replaces its former second bespoke property with one real native TOR enchantment, blessing or Dawi rune. Individual piece effects are always active. Set tiers remain cumulative at 2/5, 3/5, 4/5 and 5/5 equipped pieces.

Admin and encounter-hero copies use isolated signature traits while retaining the same native enchantment payload. Native enchantments are not recreated as custom stat approximations; their TOR `ItemTraitStringId` is stored directly.
